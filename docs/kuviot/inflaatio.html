Inflaatio

Kolme mittaria samasta ilmiöstä. Kuluttajahintaindeksi (KHI) on kansallinen inflaatiomittari, yhdenmukaistettu kuluttajahintaindeksi (YKHI) EU-maiden vertailukelpoinen indeksi, ja YKHI:n ennakko on kuukauden lopussa julkaistava pikaestimaatti, joka tulee saataville noin kaksi viikkoa ennen varsinaista julkistusta. YKHI kiintein veroin (YKHI-KIVE) kertoo, paljonko inflaatiota jäisi jäljelle ilman välillisten verojen muutoksia.

Sivu lukee kolmea taulua, ja mikä tahansa niistä päivittyy, kuvio rakennetaan uudelleen. Ennakkotaulu päivittyy kuukauden vaihteessa, KHI ja YKHI kuukauden puolivälissä.

Vuosimuutos

Näytä koodi 
library(visu)

khi <- pxwebtools::pxw_get_data(
  url = "https://pxdata.stat.fi/PxWeb/api/v1/fi/StatFin/khi/15b5.px/",
  query = list(
    "timeperiod_m" = "*",
    "coicop_46_20231201" = "SSS",
    "contentscode" = "vm_khi"
  )
)

ykhi <- pxwebtools::pxw_get_data(
  url = "https://pxdata.stat.fi/PxWeb/api/v1/fi/StatFin/khi/15b7.px/",
  query = list(
    "timeperiod_m" = "*",
    "coicop_46_20231201" = "SSS",
    "contentscode" = "vm_ykhi"
  )
)

ennakko <- pxwebtools::pxw_get_data(
  url = "https://pxdata.stat.fi/PxWeb/api/v1/fi/StatFin/khi/15b9.px/",
  query = list(
    "timeperiod_m" = "*",
    "coicop_46_20231201" = "SSS",
    "contentscode" = "vm_ykhi_ennakko"
  )
)

muutos <- rbind(
  data.frame(time = khi$time, sarja = "Kuluttajahintaindeksi (KHI)", values = khi$values),
  data.frame(time = ykhi$time, sarja = "Yhdenmukaistettu (YKHI)", values = ykhi$values),
  data.frame(time = ennakko$time, sarja = "YKHI, ennakko", values = ennakko$values)
)

muutos$sarja <- factor(muutos$sarja, levels = c(
  "Kuluttajahintaindeksi (KHI)", "Yhdenmukaistettu (YKHI)", "YKHI, ennakko"
))

# Ennakkotaulu kattaa vain kulumassa olevan vuoden, joten koko historia
# hukuttaisi sen. Kaikkia sarjoja rajataan samalta kohdalta.
alku <- seq(max(muutos$time), by = "-8 years", length.out = 2)[2]
muutos <- muutos[muutos$time >= alku, ]

muutos |>
  visu_plot(colour = "sarja", title = "Kuluttajahintojen vuosimuutos, %") |>
  visu_interactive(caption = "Lähde: Tilastokeskus, kuluttajahintaindeksi")

Mistä vuosimuutos syntyi

Näytä koodi 
library(visu)

paaryhmat <- c(
  "01" = "Elintarvikkeet",
  "02" = "Alkoholi ja tupakka",
  "03" = "Vaatetus ja jalkineet",
  "04" = "Asuminen ja energia",
  "05" = "Kalusteet ja kodinhoito",
  "06" = "Terveys",
  "07" = "Liikenne",
  "08" = "Informaatio ja viestintä",
  "09" = "Kulttuuri ja vapaa-aika",
  "10" = "Koulutus",
  "11" = "Ravintolat ja hotellit",
  "12" = "Vakuutus- ja rahoituspalvelut",
  "13" = "Muut tavarat ja palvelut"
)

vaikutus <- pxwebtools::pxw_get_data(
  url = "https://pxdata.stat.fi/PxWeb/api/v1/fi/StatFin/khi/15b5.px/",
  query = list(
    "timeperiod_m" = "*",
    "coicop_46_20231201" = names(paaryhmat),
    "contentscode" = "vv_khi"
  )
)

# Vaikutukset lasketaan vain nykyisella perusvuodella, joten sarja on lyhyt ja
# poikkileikkaus viimeisimmasta kuukaudesta kertoo siita enemman kuin aikasarja.
# Pylvaat suuruusjarjestykseen: taso muodostaa tekijajarjestyksen.
viimeisin <- vaikutus[!is.na(vaikutus$values) & vaikutus$time == max(vaikutus$time[!is.na(vaikutus$values)]), ]
viimeisin <- viimeisin[order(viimeisin$values), ]
viimeisin$ryhma <- factor(
  paaryhmat[as.character(viimeisin$coicop_46_20231201)],
  levels = paaryhmat[as.character(viimeisin$coicop_46_20231201)]
)

kuvio <- visu_plot(
  viimeisin,
  x = "ryhma",
  type = "col",
  title = paste0(
    "Hyödykeryhmien vaikutus vuosimuutokseen ",
    format(max(viimeisin$time), "%m/%Y"), ", %-yksikköä"
  )
)

visu_interactive(
  kuvio + ggplot2::coord_flip(),
  subtitle = "Pääryhmien vaikutukset summautuvat kokonaisindeksin vuosimuutokseen",
  caption = "Lähde: Tilastokeskus, kuluttajahintaindeksi"
)

Lähde: Tilastokeskus, kuluttajahintaindeksi, taulut 15b5, 15b7 ja 15b9.
