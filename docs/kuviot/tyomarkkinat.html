Työmarkkinat

Tiedot päivitetty 21.9.2026 klo 12:34.

Työvoimatutkimuksen tärkeimmät tunnusluvut kuukausitasolla ja palkansaajien määrä vuositasolla. Alkuperäinen sarja kertoo, mitä kuukaudessa mitattiin, ja trendisarja sen, mihin suuntaan työmarkkinat ovat menossa. Ne ovat samassa kuviossa samalla värillä eri paksuisin viivoin, koska kyse on samasta ilmiöstä eri tavalla siloitettuna.

Tasot ovat suoraan tilastosta. Tilasto ei julkaise vuosimuutoksia, joten ne lasketaan tällä sivulla alkuperäisestä sarjasta 12 kuukauden takaiseen verrattuna — määristä henkinä ja asteista prosenttiyksikköinä. Saman sarjan taso ja muutos ovat kuvion välilehdillä, ja kuvion alta saa ruotsin- ja englanninkielisen version ladattavana kuvana.

Kolme alinta kuviota on kausitasoitettu sivustolla itse, koska tilasto ei julkaise niistä kaikista tasoitettua sarjaa. Menetelmä on X-13ARIMA-SEATS eli sama kuin Tilastokeskuksella, ja mallit on kiinnitetty ja kirjattu tiedostoon site/_visu_seasonal.json; niistä estimoidaan joka ajolla vain parametrit. Tulos ei silti ole sama kuin tilaston oma tasoitus. Työllisistä, joista molemmat ovat olemassa, ero on keskimäärin 8 000 henkeä eli 0,3 prosenttia. Kuvion selitteessä lukee, milloin kausitasoitus on omaa laskentaa.

# Vaestotaulusta haetaan kerralla myos seuraavien kuvioiden sarjat, jotta
# samaa taulua ei kysyta rajapinnasta kolmesti.
vaesto_taulu <- visu_get_data(
  url = "https://pxdata.stat.fi/PxWeb/api/v1/fi/StatFin/tyti/135y.px/",
  query = list(
    "timeperiod_m" = "*",
    "sukupuoli_9_20180101" = "SSS",
    "ikaryhma_19_20190101" = c("15-74", "15-64", "20-69"),
    "contentscode" = c("tyti-Vaesto", "tyti-Tyolliset",
                       "tyti-Tyollisyysaste", "Tyovoimaosuus")
  )
)

# Leveaksi, jotta tyolliset ja tyottomat osuvat varmasti samalle kuukaudelle.
kausi <- stats::reshape(
  as.data.frame(tunnusluvut[c("time", "contentscode", "values")]),
  idvar = "time", timevar = "contentscode", direction = "wide"
)
names(kausi) <- sub("^values\\.", "", names(kausi))

vaesto <- vaesto_taulu[vaesto_taulu$contentscode == "tyti-Vaesto" &
                         vaesto_taulu$ikaryhma_19_20190101 == "15-64", ]

# Tyovoima on maaritelmaltaan tyolliset ja tyottomat yhteensa, joten sen
# kausitasoitettu sarja on osiensa summa. Vaesto ei kaipaa kausitasoitusta:
# se on kannan suure, joka muuttuu muutamia tuhansia kuukaudessa.
osat <- list(
  vaesto = data.frame(time = vaesto$time, values = vaesto$values),
  tyovoima = data.frame(time = kausi$time,
                        values = kausi$Tyolliset_kausi + kausi$Tyottomat_kausi),
  tyolliset = data.frame(time = kausi$time, values = kausi$Tyolliset_kausi),
  tyottomat = data.frame(time = kausi$time, values = kausi$Tyottomat_kausi)
)

# Muutos yhteisesta lahtokohdasta, jotta eri kokoiset kannat ovat samassa
# kuviossa vertailukelpoisia: tyollisia on kymmenkertaisesti tyottomiin nahden.
perusta <- as.Date("2019-01-01")
tarjonta <- do.call(rbind, lapply(names(osat), function(nimi) {
  d <- osat[[nimi]]
  d <- d[order(d$time), ]
  d <- d[d$time >= perusta, ]
  data.frame(time = d$time, sarja = nimi, values = d$values - d$values[1])
}))
