Suhdannekuva

Tiedot päivitetty 29.9.2026 klo 9:59.

Kaksi kuukausittain julkaistavaa mittaria, jotka kertovat talouden käänteestä ennen neljännesvuositilinpitoa. Tuotannon suhdannekuvaaja on kansantalouden tuotannon kuukausikuva, ja kuluttajien luottamusindikaattori kertoo miten kotitaloudet odottavat talouden kehittyvän.

Alkuperäinen, kausitasoitettu ja trendi ovat samassa kuviossa samalla värillä eri paksuisin viivoin: kyse on samasta ilmiöstä eri tavalla siloitettuna.

Toimialoittain tilasto julkaisee vain alkuperäisen ja työpäiväkorjatun sarjan, joten toimialakuvion trendi on kausitasoitettu sivustolla itse samalla X-13ARIMA-SEATS-menetelmällä kuin tilastossa. Kokonaistuotannossa, josta molemmat ovat olemassa, oma trendi poikkeaa julkaistusta keskimäärin 0,4 indeksipistettä eli alle puoli prosenttia tasosta.

kuvio <- function(kieli) {
  t <- tekstit[[kieli]]
  d <- tuotanto
  # Karkeimmasta siloitetuimpaan, jolloin viiva paksunee jarjestyksessa.
  d$sarja <- factor(d$contentscode, levels = names(t$sarjat), labels = t$sarjat)
  visu_plot(d, linewidth = "sarja", title = t$otsikko, caption = t$lahde, lang = kieli)
}

kuvio("fi") |>
  visu_interactive(caption = tekstit$fi$lahde)

# Tilasto julkaisee vuosimuutoksen alkuperaisesta ja tyopaivakorjatusta

# prosenttiyksikkoa, mika on julkaistun indeksin pyoristysta.

) |>
  group_by(contentscode) |>
  mutate(muutos = visu_change(values, time)) |>
  ungroup()

toimialat <- c("A", "BTF", "GTT")

# Tilasto julkaisee toimialoittain vain alkuperaisen ja tyopaivakorjatun
# sarjan, ei kausitasoitettua eika trendia, joten trendi lasketaan itse
# alkuperaisesta sarjasta. X-13 valitsee samalla tyopaiva- ja
# paasiaiskorjauksen, eli kalenterivaihtelu tulee huomioiduksi.
tuotanto_toimiala <- visu_get_data(
  url = "https://pxdata.stat.fi/PxWeb/api/v1/fi/StatFin/ktkk/132f.px/",
  query = list(
    "timeperiod_m" = "*",
    "toimiala_79_20180101" = toimialat,
    "contentscode" = "ind_tasm_2015"
  )
) |>
  filter(!is.na(values)) |>
  visu_seasonal("ktkk-132f-toimiala", by = "toimiala_79_20180101")
